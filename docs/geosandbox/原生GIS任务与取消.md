# 原生 GIS 导入任务与取消

更新：2026-11-17。本批只接管空间装配面板中的原生 GIS 导入，复用 GeoLibre 的 `conversion._start_job`、`_run_conversion_job` 和 `_cancel_job`。不另建通用队列，不接收客户端提供的脚本、解释器或磁盘路径。

## 使用与状态

在“空间装配 → 数据”检查文件并导入。GIS 计算在独立 Python/GDAL 进程运行，原有矢量/栅格解析逻辑提取为共享函数，兼容上传接口仍可调用。源 CRS 缺失、覆盖方式、数量限制及 GeoTIFF 预览与原件的区别保持原有契约。

前台取消进入“正在停止”，保持导入按钮禁用，等待后台进程退出确认。确认失败时显示“后台停止未确认”，旧结果不加入项目。取消请求使用独立限时连接，提交或取消回复丢失时按已生成的 UUID 查询，不重新提交输入。正常完成也检查项目版本，旧项目结果不会写入新项目。导入的项目处理历史使用 `native-gdal` 引擎名。

数据页后台列表展示最近 20 项计算记录，刷新网页后仍可查看。后台“完成”只表示计算结果已发布，不表示已加入当前项目；列表不会自动重放导入。失败、中断后重新选择原文件重试，每次生成新任务编号。

| 状态 | 含义 |
| --- | --- |
| pending | 输入保存或启动计算 |
| running | 子进程计算，阶段来自受控消息 |
| cancelling | 已请求停止，仍待进程退出确认 |
| cancelled | 本次计算已停止，结果不对外提供 |
| succeeded | 子进程退出，原件/预览与结果已提交，结果 SHA-256 已保存 |
| failed | 启动、校验、计算、超时或提交失败 |
| interrupted | 服务重启后发现旧未完成记录，不声称成功或自动续算 |

`processStopped: true` 只来自本次服务管理的进程退出确认或尚未启动的取消。中断记录为 `null`，不凭旧 PID 杀进程或推断是否仍运行。Windows 子进程使用父进程的只读同步句柄监视服务退出，父服务被强制关闭后子进程自行结束。

## 文件与边界

- `.geosandbox/native-jobs/<UUID>/job.json` 保存状态、原文件字节数/哈希、结果哈希及阶段；内部进程号不返回页面。
- 原始输入先原子保存至任务目录。成功后原件及影像预览发布到已有 `assets` 目录，结果 JSON 原子提交后才标为成功。
- 取消、失败和中断的结果不提供读取；原件与临时数据可能保留。现阶段没有自动清理，不删除已有资源。
- 同时最多 2 个原生导入任务，并受既有转换运行器的全局 8 项限制；原件 128 MiB、结果 JSON 64 MiB、计算 120 秒。
- HTTP 写接口复用本地来源检查；子进程只继承必要的系统/GIS 环境，DeepSeek 等 API 密钥不传入。
- 这些限制不等于操作系统内存隔离；单机本地服务尚未具备公网多用户权限隔离。

## 本地接口

前端 `/sandbox-api` 经代理映射至后端 `/sandbox`。

| 方法/路径（后端） | 用途 |
| --- | --- |
| POST `/sandbox/native-jobs/{id}` | multipart `file`、`kind`。`operation=inspect` 读取矢量图层和已声明 CRS，默认执行导入。`layer_crs` 接收图层名到 CRS 的 JSON 映射，`source_crs` 与 `force_crs` 适用于单图层。同编号不重复启动 |
| GET `/sandbox/native-jobs` | 最近 20 项记录 |
| GET `/sandbox/native-jobs/{id}` | 查询状态；发现旧未完成任务时标记中断 |
| POST `/sandbox/native-jobs/{id}/cancel` | 请求停止，等待最多 5 秒后返回最新状态，可继续查询 |
| GET `/sandbox/native-jobs/{id}/result` | 只读取成功且哈希通过的 JSON，其他状态返回 409 |

取消先于提交到达时写入取消记录，迟到提交不能再启动计算。已成功计算后才收到取消时保留成功记录，前台仍以自身取消信号阻止应用。

## 验收与剩余工作

`scripts/geosandbox-accept.ps1 -Build` 包含前台取消/丢回复、原生任务真实子进程、共享 conversion 回归、既有 GIS/保存/恢复和固定成果检查。本批 86 项前端、139 项后端测试、生产构建与 ESLint 通过。

浏览器验收：`http://127.0.0.1:5173/`，项目 Playwright + 已安装 Edge，1280×720 / 390×844。覆盖 GPKG 和 GeoTIFF、运行中取消、停止回执等待、列表停止按钮、提交/取消回复丢失、取消后重试与刷新后记录。无未捕获页面异常；受控丢包网络错误和既有 Cesium 导入迁移/地形轮廓、底图图标、无头软件渲染 ReadPixels 性能警告保存在记录中，未将其写成“零警告”。

独立服务实验强制结束拥有受控慢任务的服务进程，确认原生子进程退出，再启动服务：旧任务中断、结果不可读、原件字节保持。实验脚本与原件均在 D 盘，不向产品加入测试端点。

构造数据与受控慢任务不代表真实业务性能。

尚待后续：任务/资产清理及总容量管理、自动续算、上游其他工具统一接入、完整操作审计、OS 内存限制和真实业务数据基准。兼容的同步上传接口仍不支持进程级取消。M1 仍未整体完成。
