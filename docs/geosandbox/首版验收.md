# GeoSandbox 0.1.0 首版验收

首版面向单用户独立实例。主流程为导入数据、检查坐标和格式、编辑或配准模型、保存和恢复项目，再选择交付格式。Linux amd64 使用 [单用户服务器部署](单用户服务器部署.md)，Windows 本机使用 [本地运行说明](../../GeoSandbox使用说明.md)。

| 验收范围 | 结果 |
| --- | --- |
| 数据导入 | GeoJSON、ZIP SHP、GPKG、GeoTIFF 与自包含 GLB/glTF 有独立格式检查路径。真实三格式混合项目包保留原件及散列。 |
| 模型编辑 | 实例变换和命名组合可撤销、重做及保存。重开后可以再次放置组合副本。 |
| 控制点配准 | 局部平面刚体或相似变换，独立检查点参与验证。实测地图拾点、超限拦截、应用、撤销、重做和重开。用 PROJ 生成构造控制点进行独立校验。 |
| 交付 | GeoJSON、GeoPackage、Shapefile ZIP 可先检查格式差异，再生成文件。893 个机场点及其 40 个原始属性列通过独立交叉读取。静态 GLB 和项目包分别核对了锚点和资源散列。 |
| 项目恢复 | 本机恢复点按项目 ID 保护；服务器保存的项目包在容器重启后仍能重开，下载内容的 SHA-256 与保存回执一致。 |
| 服务器与凭据 | Linux amd64 镜像构建并可导入。空数据卷启动，验证匿名拦截、有效账号访问、不同来源写入拒绝、服务端持久保存和重启重开。用测试配置核对 AI 路由和公开配置。 |

已验收的控制点配准使用 5 公里内的水平坐标。矢量交付使用 WGS84；GeoPackage 与 Shapefile 写二维，GeoJSON 可保留附加坐标维度。GeoTIFF 的地图显示是预览，原件随项目包保留。项目包资源展开限额 256 MiB，自包含模型单资源限额 24 MiB。详见 [本地运行说明](../../GeoSandbox使用说明.md)。

## 交付和证据

- Linux amd64 镜像 `GeoSandbox-0.1.0-linux-amd64.tar.gz` 为 326,419,175 字节，经 `docker load` 验证与构建镜像一致。配套文件为 `GeoSandbox-0.1.0-linux-amd64.sha256`。从交付目录用 Compose 和 `--no-build` 启动也通过登录、保存及重启验收，见 `linux-qa/server-portable.log`。
- 实际下载的开放样本、来源、预期结构和 SHA-256 见 [开放数据验收样本](开放数据验收样本.md)。
- 前端全量测试 14,238 通过、2 跳过。本机发布校验 `scripts/geosandbox-accept.ps1 -Build` 的 100 项前端专项、164 项后端专项、固定成果和生产构建通过。
- 发布镜像内运行 Docker 配置和后端全量用例，629 通过、53 跳过，日志见 `linux-qa/backend-release.log`。测试环境从缓存加载对应 Linux 版本的 DuckDB Spatial 扩展。

镜像烟测使用回环地址和独立数据卷。实际服务器按部署文档提供 HTTPS 来源、域名证书和自己的账号。DeepSeek 生产凭据由部署者按需要配置。
