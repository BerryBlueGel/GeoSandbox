# GeoSandbox 复用决策

基线：GeoLibre 3.8.0，提交 c0f5513930a4675c503e696ae66a475dfca6fb39（MIT）。保留根 LICENSE 和原项目归属。

在创建自有功能前检查了官方文档与实际源码。采用现有 React/npm monorepo，不另建 Vue、OpenLayers、命令历史、数据驱动模型渲染或空间处理框架。

| 目标              | 直接复用                                                                     | 本项目补充                                                             |
| ----------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 格式识别/坐标信息 | file-type 22.3.0（MIT）、file-io、DuckDB Spatial、shpjs、GDAL/Rasterio、PROJ | 二进制签名、JSON/ZIP 结构诊断、统一确认入口、显式 CRS 纠正与原标注记录 |
| 二三维            | MapEngine、MapLibre、Cesium、deckgl-viz                                      | 装配面板和实例编辑                                                     |
| 历史与项目        | Zustand/zundo、projectFromStore、现有快照/历史                               | 通过 store 提交实例变更；资源打包与校验                                |
| 矢量合并          | merge-layers 算法及现有 ProcessingDialog                                     | 数据页快捷入口                                                         |
| 轮廓定位          | core.diagramAnchor                                                           | 可预览的实例中心对齐；不称为自动模型配准                               |
| GLB 读写/组装     | glTF Transform、现有 local-gltf 校验                                         | 地理锚点说明、装配输出                                                 |
| 尺寸与单位校准    | glTF Transform getBounds / getSceneVertexCount                               | 显示静态包围盒、人工源单位或已知宽度、绝对倍率预览                     |
| 多模型整体编辑    | Cesium ENU / Matrix3 / Matrix4、现有 Zustand/zundo                           | 局部米制锚点、批量方案和原子提交，不另建坐标或撤销引擎                 |
| GeoTIFF 显示预览  | Rasterio/GDAL 的 WarpedVRT 和 PNG 驱动、现有 image 图层                      | 限定分辨率和拉伸、保留原件，绕开本机出现停顿的三维 WASM 路径           |
| AI                | 现有 assistant 工具、Strands、自定义兼容提供方                               | 本地 DeepSeek 代理、模型参数与配置状态保存在 D 盘                      |
| 本机密钥保管      | keyring 25.7.0、Windows WinVault                                             | 旧明文配置经系统库写入校验后迁移；配置文件只记录状态                   |

项目恢复继续复用 `useProjectHistory`、IndexedDB 快照存储、`ProjectHistoryDialog` 的比较/恢复能力，只新增“查看全部项目历史”的入口。D 盘最近项目直接索引已有成果目录，打开时继续走 fflate 及 SHA-256 校验，不创建第二套项目数据库。文件列表保留原成果、不删除旧版本。

进一步复用候选：Open3D 全局配准/ICP（需重叠和适当数据条件），GDAL 控制点变换/镶嵌，PROJ 坐标定义识别。它们均不能保证从缺失信息确定任意 CRS、对任意不相干模型自动拼接、或让表达能力不同的格式无损互转。

项目源码、依赖、数据和构建都在仓库目录。任务缓存默认在仓库同级的 `.geosandbox-cache`。密钥由系统用户凭据库保管，位置由 Windows 管理。不修改全局用户缓存位置，不迁移其他项目或 Docker 数据。

界面设计沿用原有白色界面、蓝色状态、薄边框和组件。地图内容取决于真实加载的数据，概念图中的校园背景不作为生产图片使用。

视觉对照记录：

1. 保留白色顶栏与蓝色“空间装配”入口，对应概念图的导航位置。
2. 右侧采用 360px 装配面板、模型/组合/数据/交付四页；本轮为多模型编辑单独增加组合页，桌面保留地图操作区域。
3. 实例位置/朝向/缩放使用成对数值输入；应用变换为蓝色主按钮，复制/删除为次级按钮。
4. 保留上游左侧真实图层树、样式与元数据操作；概念图左侧较简化，这是为了实际数据管理的有意差异。
5. 示例由 glTF Transform/Three 生成真实 GLB，并加载实际地理要素；没有把概念图校园插画铺在地图中伪装运行效果。
6. 添加二维/三维、撤销/重做、地图拖动定位和批量轮廓方案，属于实际闭环所需控件，因此面板需要滚动。
7. 窄屏使用全宽面板且层级高于移动图层浮窗；长路径换行，避免横向撑出。桌面和 390px 窄屏均检查。
