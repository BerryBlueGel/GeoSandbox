独立核验使用 Pyogrio、Rasterio 和 GLB 文件解析。配准用的控制点和预期目标位置由 [PROJ topocentric](https://proj.org/en/stable/operations/conversions/topocentric.html) 生成，和真实样本的来源各自记录。模型的目标位置是构造验收条件，未使用实地测量坐标。Natural Earth 机场点用于验证 GIS 格式读写，其比例尺和定位来源不适合作为近距离配准的真值。

Edge 验收覆盖三份原件导入、地图拾点、坏检查点拦截、应用、撤销、重做、GLB 导出和项目包重开。独立读取最终约 64.7 MiB 项目包，核对原始三份文件哈希、893 个机场要素、配准报告和 GLB 锚点。模型位置和检查点通过 2 厘米的构造用例容差。

同一份机场数据从交付页分别写出 GeoJSON、GeoPackage 和 Shapefile ZIP。Pyogrio/GDAL 独立读取三份成果，确认全部 893 个点的坐标、EPSG:4326 及机场代码一致。GeoJSON 的 Feature ID 由读取器另呈现为一列。页面已在 390 px 窄屏验证格式差异确认。
