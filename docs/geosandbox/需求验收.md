# GeoSandbox 对照原始需求的验收标准

目标是“自由空间沙盒”，保留常用 GIS 数据处理：文件进入同一工作区，完成定位、单位校准、组合、编辑与可追溯导出。采用 GeoLibre 原项目，继续复用现有解析器、渲染器、处理算法和历史机制。

| 原始需求                   | 实现与验收标准                                                                                                                                                                                                              |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 直接导入常用二维、三维数据 | GeoJSON、ZIP Shapefile、GeoPackage、GeoTIFF、自包含 GLB/glTF；新增检查式统一入口，GLB 快速入口和原有添加数据菜单保留。                                                                                                      |
| 识别各种数据类型           | file-type 检查二进制内容，JSON 检查要素/模型结构，ZIP 检查项目清单或 SHP 组件；扩展名错误会提示并按内容选择解析器；未知内容不会伪装成已识别，可手动指定受支持解析方式。                                                     |
| 坐标和单位识别             | 已声明 CRS 交给 GDAL/PROJ；缺失 CRS 明确失败并允许补充。已确认误标时可显式覆盖，另存原标注；无效经纬度结果被拒绝。glTF 按标准米解释，显示静态尺寸，支持厘米、毫米、英尺倍率或已知实际宽度校准。没有依据时不猜测单位或 CRS。 |
| 合并为选定类型加载         | 矢量追加合并复用上游算法，保留源图层、补齐字段和来源；静态模型实例可装配成 GLB，或保持分图层编辑后保存整个项目。                                                                                                            |
| 自动或手动拼接             | 具备已有地理坐标时自动叠加、轮廓中心定位/批量摆放、地图拖动、数值变换、多模型整体平移/旋转/缩放。缺少语义、重叠或控制点的任意模型不承诺自动配准。                                                                           |
| 模块化单位                 | 明确定义为矢量要素、模型实例及其图层；模型可复制、删除、单实例编辑或多图层整体变换。没有语义结构的单个网格不自动猜出房屋、道路等内部边界。                                                                                  |
| 自行修改、添加、删除       | 模型实例面板与地图定位；矢量沿用现有 GeoEditor、属性与图层操作。原始资产保留，变换写入实例数据。                                                                                                                            |
| 回退与前进                 | 单实例变换、校准与多模型方案复用 Zustand/zundo；多模型一次应用写入一次状态，因此一步撤销全部所选模型。旧方案任一目标变化时整体拒绝。                                                                                        |
| AI 辅助任务                | DeepSeek 真实接口；模型读取、单实例变换、单位/宽度校准、整体装配四类沙盒工具。修改先生成方案，人工应用；无效参数不修改数据。密钥由系统凭据库保管。                                                                          |
| 多格式导出                 | 项目包保留当前状态与原始资源，按 SHA-256 校验；静态模型 GLB 加地理锚点 JSON；GIS 单层导出沿用现有工具。格式表达能力不同，不承诺任意格式无损互转。                                                                           |

## 本轮必须通过的检查

- 真正的 GLB、GPKG、TIFF 和 SHP ZIP 改成错误扩展名后，仍按内容识别。
- 无效文本即使命名为 `.glb` 也不能被当作模型；错误指定解析方式不能悄悄创建图层。
- 37 × 12.5 × 17 的构造模型校准为厘米后显示 0.37 × 0.125 × 0.17 米；按 18.5 米宽度校准时倍率为 0.5，重复预览不累乘。
- 组合平移的单位为米；旋转和缩放同时改变相对间距及每个实例自身的方向和大小。只改高度不改变经纬度。
- 两个模型图层一次提交、一次撤销和重做；一个目标已变化则全部不应用，未选中的图层保持原状。
- 保存、重新打开项目与 GLB 输出保留数量、位置、倍率和来源资产。检查资源哈希与独立距离基准。
- 桌面与窄屏能操作，不出现空白页、框架错误覆盖层或本轮流程控制台错误。

## 能力边界

统一检查入口单文件 128 MiB；单个内嵌 glTF/GLB 24 MiB；便携包展开资源 256 MiB。组合编辑支持 1 ～ 64 个模型图层、最多 2000 个实例，实例位置及变换结果限在首实例锚点 5 km 内。

GeoTIFF 为有界显示预览，原始波段另存保留；GLB 装配不等于布尔融合、网格焊接或重建。动画/骨骼可作为原件保存，当前装配导出会明确拒绝。高度为相对地面偏移，不是已烘入地形的绝对海拔。

专业点云配准、影像控制点配准、外部分离纹理自动打包、多人协作和超大数据分页仍有后续扩展空间；不能用“满足本轮验收”替代这些尚未完成的能力。
